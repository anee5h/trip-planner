# Architecture & Implementation Plan: v1.6.0 — Destination Relationship Model

Transform TabiMap's destination model from a flat collection of places into a relationship-based system where cities, wards, towns, villages, attractions, castles, shrines, and landmarks remain first-class destinations while supporting rich parent-child navigation and peer recommendations.

---

## 1. Core Architectural Strategy & Graph Model

```text
Japan
│
└── Aichi Prefecture (Administrative)
    │
    └── Nagoya City (Hub Destination)
        │
        ├── Nagoya Castle (POI Destination)
        ├── Atsuta Shrine (POI Destination)
        ├── Osu Shopping Street (POI Destination)
        └── SCMAGLEV Museum (POI Destination)

Nearby Municipalities (Peer Edge)
──────────────────────────────
Inuyama City
Toyota City
Okazaki City

Thematically Related (Peer Edge)
──────────────────────────────
Kyoto City
Osaka City
```

```text
Destination Graph (Flat Entity Model with Grouped Navigational Relationships)
    │
    ├── role: "hub" | "poi"
    ├── importance: "major" | "notable" | "standard"
    ├── kind: "city" | "ward" | "town" | "village" | "castle" | "temple" | "shrine" ...
    ├── status: "active" | "coming-soon" | "hidden"
    ├── aliases?: string[]                (e.g., ["Nagoya", "名古屋", "名古屋市"])
    ├── prefecture: string                (Provides administrative geography)
    ├── region: string
    │
    └── relationships?: DestinationRelationships
            ├── parentDestinationId?: string      (Primary container parent, e.g. "nagoya-castle" -> "nagoya-city")
            ├── featuredDestinationIds?: string[] (Strictly curated editorial top sights for a hub page)
            ├── nearbyDestinationIds?: string[]   (Neighboring municipalities or nearby sights)
            └── relatedDestinationIds?: string[]  (Thematically related / "You may also like" sights)
```

### Invariants & Ownership Rules

- **Navigational Metadata**: Relationships exist strictly to power UI navigation and recommendations. They must never duplicate or replace canonical destination data (`prefecture`, `region`, `collections`).
- **Immutable IDs**: Destination IDs are immutable and globally unique. Relationships always reference IDs, never display names.
- **Hub Ownership**: Only parent hubs define `featuredDestinationIds` and `nearbyDestinationIds`. Children never store inverse arrays; the UI infers parent links cleanly.
- **Editorial `featuredDestinationIds`**: `featuredDestinationIds` is strictly curated editorial content (never auto-generated).
- **Fallback Precedence for Nearby**: Explicit `nearbyDestinationIds` → Same `parentDestinationId` → Same `prefecture`.
- **O(1) Service Indexing**: `DestinationRelationshipService.ts` maintains lookup maps (`destinationsById`, `childrenByParentId`) for instant performance.

#### [NEW] `src/shared/services/destination/DestinationRelationshipService.ts`

Indexed service for graph relationship queries:

```typescript
import type { Destination } from "@/shared/types/destination";
import { getDestinationList } from "./DestinationService";

export class DestinationRelationshipService {
  private static byId: Map<string, Destination> | null = null;
  private static childrenByParent: Map<string, Destination[]> | null = null;

  private static initIndex() {
    if (this.byId) return;
    const all = getDestinationList() as Destination[];
    this.byId = new Map(all.map((d) => [d.id, d]));
    this.childrenByParent = new Map();

    for (const d of all) {
      const parentId = d.relationships?.parentDestinationId;
      if (parentId) {
        if (!this.childrenByParent.has(parentId)) {
          this.childrenByParent.set(parentId, []);
        }
        this.childrenByParent.get(parentId)!.push(d);
      }
    }
  }

  static getParent(destination: Destination): Destination | null {
    this.initIndex();
    const parentId = destination.relationships?.parentDestinationId;
    return parentId ? this.byId?.get(parentId) || null : null;
  }

  static getFeaturedChildDestinations(city: Destination): Destination[] {
    this.initIndex();
    const featuredIds = city.relationships?.featuredDestinationIds || [];
    return featuredIds
      .map((id) => this.byId?.get(id))
      .filter(Boolean) as Destination[];
  }

  static getNearbyDestinations(destination: Destination): Destination[] {
    this.initIndex();
    const rels = destination.relationships;
    if (rels?.nearbyDestinationIds?.length) {
      return rels.nearbyDestinationIds
        .map((id) => this.byId?.get(id))
        .filter(Boolean) as Destination[];
    }
    if (rels?.parentDestinationId) {
      const siblings =
        this.childrenByParent?.get(rels.parentDestinationId) || [];
      return siblings.filter((d) => d.id !== destination.id);
    }
    const all = getDestinationList() as Destination[];
    return all
      .filter(
        (d) =>
          d.prefecture === destination.prefecture && d.id !== destination.id,
      )
      .slice(0, 4);
  }
}
```
