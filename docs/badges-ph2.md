# 🪷 Three Great Buddha Statues (日本三大仏)

This one is **disputed**, so I'd use the most widely accepted modern interpretation:

- **Great Buddha of Nara** (Todai-ji)
- **Great Buddha of Kamakura** (Kotoku-in)
- **Great Buddha of Takaoka** (Toyama)

> _Alternative third choices such as Gifu Great Buddha also exist. Consider documenting the source you use in TabiMap._

---

# 🦊 Three Great Inari Shrines (日本三大稲荷)

Another list with multiple traditions. The most commonly accepted trio is:

- **Fushimi Inari Taisha** (Kyoto)
- **Toyokawa Inari** (Aichi)
- **Yutoku Inari Shrine** (Saga)

> _Some traditions substitute Kasama Inari (Ibaraki) for Yutoku Inari. If you implement this collection, it's worth noting in your documentation that multiple accepted lists exist._
