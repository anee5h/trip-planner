## Data-driven audit seams

- `checkedIdentityEvidence()` reads the repository identity-evidence file by
  default. Tests may pass typed synthetic reviewed-origin entries through the
  audit options; they do not mutate committed evidence.
- C2 registration is derived from `SCHEDULED_TRANSIT_DATASETS` by default. Tests
  may pass an explicit descriptor list plus typed in-memory synthetic artifacts.
  The synthetic artifact option is test-only input and does not add a registry
  entry or commit an ODPT asset. A descriptor is not trusted merely because it
  is registered: required descriptor fields, the referenced real asset (or
  supplied test artifact), loader validation, hashes, namespace, and artifact
  provenance must be valid.
- C2 distinguishes `no_registered_odpt_scheduled_dataset`,
  `registered_odpt_dataset_not_loadable`, and
  `registered_odpt_scheduled_dataset`. The current registry has only the Sakata
  GTFS descriptor, so the committed result remains
  `no_registered_odpt_scheduled_dataset`. This PR does not modify the registry
  or add a synthetic ODPT artifact.
- Anchor C2 findings and the top-level C2 boundary are projections of the same
  computed registry state: registered keys, providers, loadability, and reason
  cannot drift independently.

## Product-safe origin

The current `qa/kai-292c4a/real-corridor-identity-evidence.json` has no reviewed
stable product origin identity. The audit therefore reports no exact product
origin options and keeps `real_meguruto_origin` unsatisfied. A reviewed entry is
eligible only when `checkedIdentityEvidence()` finds:

- `identityKind: product`;
- `identityStability: stable_product_id`;
- `reviewStatus: reviewed`; and
- a non-empty `productId`.

Those IDs become `origin.reviewedProductIds` and
`origin.exactProductOriginOptions`, and the origin gate becomes satisfied. This
does not by itself create a crosswalk or corridor.

The audit rejects:

- free-text label and coordinates;
- nearest/proximity station resolution;
- geographic-anchor promotion;
- Sakata pilot identities as product origins; and
- old ODPT direct-Journey input as a C2 substitute.

No UI redesign is proposed in this slice.
