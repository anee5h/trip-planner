# One bug I would specifically investigate

One file that caught my attention is:

```
src/shared/services/DestinationService.ts
```

combined with

```
DestinationRelationshipService.ts
```

If the image issue started after introducing or expanding these services, I'd inspect whether the app is accidentally preferring a **hub image** over a **POI image** during data normalization or relationship resolution. For example, a POI like `nagoya-castle-aichi` could be inheriting the image from `nagoya-city` if there's a fallback based on parent relationships.
