# Architecture & Implementation Plan: v1.5.2 — Design System & Product Polish

Transform TabiMap's user experience through strict visual standardization and state correctness across 3 structured workstreams: **Core Infrastructure**, **Functional Correctness & Bug Fixes**, and **UX & Design System Polish**.

---

## 1. Structured Workstreams & Phased Execution

```
                       v1.5.2 Product Polish

 ┌───────────────────────────┐         ┌───────────────────────────┐
 │   PHASE 1: INFRASTRUCTURE │ ──────> │  PHASE 2: DESIGN POLISH   │
 │      & CORRECTNESS        │         │    & SYSTEM STANDARD      │
 └───────────────────────────┘         └───────────────────────────┘
   • ThemeProvider & useTheme            • Icons Registry (src/shared/icons/)
   • Base Location Single Source         • Typography Components (UI)
   • Safe Return Flow (?return=)         • Profile Hero Header Redesign
   • Data Export ("app": "TabiMap")      • Command Palette Raycast Polish
```

---

### Workstream A: Core Infrastructure

1. **`ThemeProvider` & `useTheme()`**: Create `ThemeContext.tsx` & `useTheme.ts`. ThemeProvider is the **single source of truth for application theme and the only component that mutates the root document theme classes** (`.dark`). Supports `"system" | "light" | "dark"` and system preference media queries.
2. **Unified Icons Registry (`src/shared/icons/index.ts`)**: Export a single, consistent `Icons` dictionary (`Icons.discover`, `Icons.plan`, `Icons.passport`, `Icons.profile`, `Icons.settings`, `Icons.help`, `Icons.feedback`, `Icons.action`, etc.) for single-source icon management.
3. **User Preferences Ownership**: User Preferences Store owns **Base Location**. Settings is the single entry point to edit it; Homepage, Planner, Recommendations, and Search strictly read from it.

---

### Workstream B: Functional Correctness & Bug Fixes

1. **Live Theme Switching**: Changing theme in Settings immediately updates root document classes via `useTheme()`.
2. **Safe Return Navigation Flow**: Homepage "Change" button links to `/settings?return=/`. Saving in Settings validates that `return` is a safe internal relative path starting with `/`, then automatically navigates the user back to `returnUrl` (default `/`) with a confirmation toast (_"Base Location updated to [Station]. Recommendations refreshed."_).
3. **Data Export Schema Versioning**: Export downloads a valid JSON backup with `"app": "TabiMap"` and `"schemaVersion": 1`:
   ```json
   {
     "app": "TabiMap",
     "version": "1.5.2",
     "schemaVersion": 1,
     "exportedAt": "2026-07-25T07:35:00.000Z",
     "profile": { "username": "", "email": "", "home_city": "" },
     "preferences": {
       "base_location": "",
       "carMode": "",
       "publicModes": [],
       "partySize": 2,
       "units": "metric"
     },
     "visitedDestinations": [],
     "prefectures": [],
     "trips": []
   }
   ```

---

### Workstream C: UX & Design System Polish

1. **Zero Emojis Policy**: All unicode emojis across Passport tabs, Profile tabs, Settings sidebar, Help sections, and Search Palette are replaced with clean Lucide icons from `Icons`.
2. **Streamlined Typography Components (`src/shared/components/ui/Typography.tsx`)**: Reusable React typography primitives: `<PageTitle>`, `<SectionTitle>`, `<CardTitle>`, `<BodyText>`, and `<Caption>`.
3. **Dynamic Profile Hero Header**:
   Redesign `/profile` header into an Explorer Hub hero banner featuring the user avatar, display name, dynamic join date (`"Member since " + month/year`), and a 4-stat pill bar (_Prefectures_, _Destinations_, _Badges_, _Achievements_).
4. **Command Palette (`Cmd+K`) Raycast Polish**: Row padding `py-3.5 px-4`, subtle category group dividers, and refined highlight states.
5. **Interaction & State Consistency**: Uniform transitions, focus rings (`focus:ring-2 focus:ring-emerald-500`), hover states, card elevations, disabled states (`disabled:opacity-50 disabled:cursor-not-allowed`), and loading behaviors across all routes.

## 3. Design System & Accessibility Acceptance Checklist

- [ ] No unicode emojis remain in the authenticated application UI.
- [ ] All icons originate from `src/shared/icons/index.ts`.
- [ ] Theme switching updates immediately without page refresh (`ThemeProvider` is the sole DOM mutator).
- [ ] Base Location has exactly one editable entry point (`/settings` using `<StationInput />`).
- [ ] There is exactly one implementation of `<StationInput />` reused wherever a station is selected.
- [ ] Homepage, Planner, and Recommendations display the identical Base Location.
- [ ] Homepage "Change" button navigates to `/settings?return=/` and returns user safely to Homepage after saving.
- [ ] Data Export generates a valid `tabimap_travel_data.json` file containing `"app": "TabiMap"` and `"schemaVersion": 1`.
- [ ] Command Palette spacing and category dividers are consistent across all result groups.
- [ ] Keyboard navigation works seamlessly after replacing emojis with vector icons.
- [ ] Focus rings, disabled states, and loading behaviors remain consistent and accessible across interactive components.
- [ ] Command Palette is fully keyboard operable (`ArrowUp`, `ArrowDown`, `Enter`, `Esc`).
