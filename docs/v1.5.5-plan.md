# Architecture & Implementation Plan: v1.5.5 — Passport Identity & Badge System

Transform Passport from a collection of progress cards into a personal travel identity by establishing clear, non-overlapping ownership for **Collections**, **Achievements**, and **Badges**.

---

## 1. Core Architectural Strategy & Responsibility Division

```text
Visit Event
    │
    ▼
Visit History
    │
    ├─────────────────► Collections (Owns Curated List Completion)
    │                       │
    │                       ▼
    ├─────────────────► Achievement Engine (Consumes Collection Completion & Milestones)
    │
    └─────────────────► Badge Engine (Evaluates Traveler Behavior & Identity)
                            │
                            ▼
                        Passport UI & Profile Showcase
```

### Ownership Rules

- **Collections**: Own curated list completion.
- **Achievements**: Consume collection completion and milestone events.
- **Badges**: Evaluate traveler behavior and identity.
- **Passport**: Renders these systems but owns none of their logic.

---

## 2. Refinements Incorporated (Final Frozen Architecture)

> [!IMPORTANT]
> **Final Architecture Guidelines for v1.5.5**:
>
> 1. **Pure Declarative Badge Data & `BadgeEngine`**: `Badge` objects contain pure declarative metadata (`id`, `name`, `category`, `rarity`, `description`, `howToEarn`, `illustrationId`, `unlockRule`, `introducedIn`). Evaluation logic is isolated inside `BadgeEngine.ts` (`BadgeEngine.evaluateAll(ctx)`).
> 2. **Scalable Illustration Data**: `BadgeIllustrationId = string` so adding new badges is purely data-driven.
> 3. **Zero Progress Bars on Badges**: Progress bars and `21/24` fraction text are completely removed from Badges. Badges display a clean **Unlocked / Locked** enamel pin state.
> 4. **Conservative Rarity Tiers**:
>    - **Common** (~10–12 badges)
>    - **Rare** (~6–8 badges)
>    - **Epic** (~2–3 badges)
>    - **Legendary** (~1–2 badges, e.g. _Japan Complete_ with gold foil border & enamel glow)
> 5. **Showcase Badges on Profile**: Users can select up to 4 favorite badges ("Add to Showcase") to display on their `/profile` hero header.

## 3. Proposed Code Changes

### Data Schemas & Services

#### [NEW] `src/features/passport/types/badge.ts`

```typescript
export type BadgeCategory =
  "travel-style" | "interests" | "regional" | "experience";

export type BadgeRarity = "common" | "rare" | "epic" | "legendary";

export type BadgeIllustrationId = string;

export interface UnlockRule {
  type:
    | "visit_count"
    | "prefecture_count"
    | "category_count"
    | "tag_count"
    | "transit_mode"
    | "seasonal";
  target: number;
  targetValue?: string;
}

export interface Badge {
  id: string;
  name: string;
  category: BadgeCategory;
  categoryLabel: string;
  rarity: BadgeRarity;
  description: string;
  howToEarn: string;
  illustrationId: BadgeIllustrationId;
  unlockRule: UnlockRule;
  introducedIn?: string;
}

export type AchievementTrigger =
  | { type: "collection_complete"; collectionId: string }
  | { type: "prefecture_count"; threshold: number }
  | { type: "visit_count"; threshold: number }
  | { type: "all_regions" }
  | { type: "four_seasons" }
  | { type: "custom"; ruleId: string };

export interface Achievement {
  id: string;
  title: string;
  description: string;
  trigger: AchievementTrigger;
  badgeRewardId?: string;
  iconName: string;
}
```

```typescript
export class BadgeEngine {
  static isUnlocked(badge: Badge, ctx: BadgeContext): boolean { ... }

}
```

#### [NEW] `src/features/passport/services/AchievementEngine.ts`

#### [NEW] `src/features/passport/data/badges.ts`

## 4. Verification Plan

### Automated Tests

- Run `npx tsc --noEmit` to verify type safety across `BadgeEngine` & `AchievementEngine`.
- Run `npm run build` to verify clean production compilation.

### Manual Verification

1. Navigate to `/passport` > **Badges**.
2. Confirm **no progress bars** appear on badge cards.
3. Verify circular enamel pins display rarity borders (**Common**, **Rare**, **Epic**, **Legendary**).
4. Filter badges by category tabs (**Travel Style**, **Interests**, **Regional**, **Experience**).
5. Click any badge to open `BadgeDetailModal` and verify artwork, rarity badge, description, earned timestamp, and criteria.
6. Click "Add to Showcase" on a badge and verify it appears in the **Showcase Badges** on `/profile`.
7. Open **Achievements** and verify milestone cards reflect Collection completion events cleanly.
