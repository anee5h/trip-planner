# KAI-32 Chugoku POI claim-to-source audit

Audit date: **2026-08-12** (the single source date used for every `accessedAt`,
`checkedAt`, and `changedAt` in `scripts/kai-32-chugoku-expansion.ts`; no
pre-dated or future-dated provenance exists in this PR).

Audited baseline: PR #127 head (`b9f73278`) + this PR's own generator run.

Scope:

- 30 new Chugoku POI records (all `travelEstimate.confidence: "beta"`, no
  static transport minutes added anywhere — `transportOptions` is `{}` for
  every new record, access is described in notes text).
- 40 evidence-backed corrections to pre-existing Chugoku records.
- 12 municipal hubs gained `nameJa`.
- 11 hub featured lists rebuilt to contain only same-municipality children.

Research method: three independent V4 Flash Max research passes (Okayama
cluster, Hiroshima cluster, Shimane/Tottori/Yamaguchi cluster) that verified
each fact against primary sources (municipal government sites, official
attraction/operator sites, official tourism boards, UNESCO, Agency for
Cultural Affairs / Cultural Heritage Online, Ramsar, MLIT) between
2026-08-10 and 2026-08-12. All 30 new images and every corrected image
license were verified live against the Wikimedia Commons API (file exists,
license, artist). Coordinates were cross-checked against OSM/Nominatim,
Wikidata, and Commons geotags. LunaMax independently re-checked a sample of
these sources against the final diff.

Transport truthfulness: no train durations, ferry durations, fares, generic
bus times, or airport routes were invented. The only deliberate transport
changes remove fabricated legacy values (see pre-existing audit). Miyajima
island records are non-routable (`transportZoneId: "unknown"`) until a
ferry route exists in the registry.

### Image provenance summary (new records)

All 30 new records carry `imageMetadata` with license/attribution/sourceUrl
verified against the Wikimedia Commons API on 2026-08-12. Licenses used:
CC BY-SA 4.0 (13), CC BY-SA 3.0 (3), CC BY-SA 2.0 (1), CC BY 2.5 (6), CC BY
3.0 (2), CC BY 2.0 (1), CC0 (4). Every `sourceUrl` is the Commons file page
for the exact asset in `heroImage`. No duplicate heroes were introduced;
the only remaining `DUPLICATE_IMAGE_URL` warnings are two pre-existing
hub/child pairs (`iwakuni-city`/`kintai-bridge-yamaguchi`,
`mine-city`/`akiyoshido-cave-yamaguchi`) untouched by this PR and recorded
for follow-up.

### Japanese content guarantee

Every new record has independent `content.ja.description`, `content.ja.highlights`,
`openingHoursJa`, `notesJa`, `reservationJa`, and `parkingJa`. The generator
throws if `OPENING_HOURS_JA[id]` is missing, so Japanese operational fields
can never silently fall back to English. No record in this PR copies
`businessHours` into `openingHoursJa`.

### Budget transparency

`budgetBreakdown.transport/food/cafe` are editorial planning estimates;
`tickets` is the verified admission fee where one exists (marked V in the
research ledger) and 0 for free-access places. Transport fares are never
invented: `transportOptions` is `{}` for all 30 new records, so no static
minutes can leak into route truth. The only fare-like values are verified
on-site fees (e.g. Miyajima ropeway ¥2,000, Horikawa boat ¥2,000, Ohara
museum ¥2,000, Fukiya bus ¥800 each way) recorded in notes with their
source.
